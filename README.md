\# DevOps EC2 CI/CD Project



This project demonstrates a basic DevOps CI/CD pipeline.



\## Architecture



Developer

→ GitHub

→ Jenkins

→ Docker

→ Docker Hub

→ AWS EC2



\## Application



Python Flask application.



\## Docker



The application is packaged into a Docker image.



\## CI/CD



Jenkins automatically builds the Docker image and deploys the application.



\## Application Port



5000
